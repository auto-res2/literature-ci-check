Counting of lattices containing up to ﬁve comparable reducible
elements and having nullity up to three

Abstract
In 2020 Bhavale and Waphare introduced the concept of a nullity of a poset as nullity
of its cover graph. In 2003 Pawar and Waphare counted all non-isomorphic lattices on n
elements and n edges, which are precisely lattices of nullity one. In 2002 Thakare et al.
counted all non-isomorphic lattices on n elements containing two reducible elements. In the
same paper, Thakare et al.
counted lattices on n elements containing up to n+1 edges,
which are precisely lattices of nullity up to two. In 2024 Bhavale and Aware counted all non-
isomorphic lattices on n elements, containing up to three reducible elements. Recently, Aware
and Bhavale counted all non-isomorphic lattices on n elements, containing four comparable
reducible elements, and having nullity three. In this paper, we count up to isomorphism the
class of all lattices on n elements containing ﬁve comparable reducible elements, and having
nullity three.

Introduction
In 1940 Birkhoﬀ[5] raised the open problem, compute for small n all non-isomorphic posets/lat-
tices on a set of n elements. This NP-complete problem was attempted by many authors from
all over the world. For more details about counting of lattices see [6], [8], [10].
An element x in a lattice L is join-reducible(meet-reducible) in L if there exist y, z ∈L
both distinct from x, such that y ∨z = x(y ∧z = x). An element x in a lattice L is reducible if
it is either join-reducible or meet-reducible. x is join-irreducible(meet-irreducible) if it is not
1
join-reducible(meet-reducible); x is doubly irreducible if it is both join-irreducible and meet-
irreducible. The set of all reducible elements in L is denoted by Red(L), and its complement
in L is denoted by Irr(L). An element x in a poset P covers an element y in a poset P if
x < y, and there is no z in P such that x < z < y. We denote this fact as x ≺y, and we say
that < x, y > is covering or an edge. The height of a lattice is the number of coverings in a
maximal chain of a lattice. Lattices L1 and L2 are isomorphic (in symbol, L1 ∼= L2), and the
map φ : L1 →L2 is an isomorphism if and only if φ is one-to-one and onto, and a ≤b in L1 if
and only if φ(a) ≤φ(b) in L2. Let L1 and L2 be two lattices. By L1 ⊕L2(L1 ◦L2) we mean
linear sum(vertical sum) of lattices(see [14], [15]). If P is a poset then Irr(P) is the set of all
elements in P which have at most one lower cover and at most one upper cover in P. Bhavale
and Waphare [4] introduced the concept of a nullity of a poset P, denoted by η(P), as nullity
of its cover graph. According to Bhavale and Waphare [4], if a dismantlable lattice of nullity k
contains r reducible elements then 2 ≤r ≤2k. Bhavale and Waphare [4] also introduced the
concept of an RC-lattice, a basic block and a basic block associated to a lattice.
Deﬁnition 1.1. [4]An RC-lattice is a lattice in which all the reducible elements are comparable.
Deﬁnition 1.2. [4] A poset P is a basic block if it is one element or Irr(P) = ∅or removal of
any doubly irreducible element reduces nullity by one.
Deﬁnition 1.3. [4] B is a basic block associated to a poset P if B is obtained from the basic
retract associated to P by successive removal of all the pendant vertices.
Theorem 1.4. [4] Let B be the basic block associated to a poset P. Then Red(B) = Red(P)
and η(B) = η(P).
In 1974, Rival [13] introduced and studied the class of dismantlable lattices.
Deﬁnition 1.5. [13] A ﬁnite lattice of order n is called dismantlable if there exist a chain
L1 ⊂L2 ⊂. . . ⊂Ln(= L) of sublattices of L such that |Li| = i, for all i.
Bhavale and Waphare [4] proved that every RC-lattice is a dismantlable lattice.
Theorem 1.6. [10] A ﬁnite lattice is dismantlable if and only if it is an adjunct of chains.

Corollary 1.9. An RC-lattice L containing n elements is of nullity l if and only if L is an
adjunct of l + 1 chains, starting with a maximal chain containing all the reducible elements.

member of it is of height h.
